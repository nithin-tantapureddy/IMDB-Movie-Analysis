# IMDB Movie Dataset Analysis — EdiGlobe Minor Project

A Python data analysis and visualization project using the IMDb movie dataset. This repository contains my minor-project notebook prepared in response to the EdiGlobe assignment.

## Project objective
Analyze the IMDb movie dataset and extend the supplied project with additional analyses. The assignment specifically suggests finding the **top 5 rated movies overall** and the **top 10 rated comedy movies**; both are included.

## Analyses included
- Dataset overview, missing values and descriptive statistics
- Top 5 rated movies overall
- Top 10 rated comedy movies
- Top 10 movies by revenue
- Movie releases by year
- Average rating by year
- Average rating by genre
- Average runtime by genre
- Relationship between ratings and votes

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook / Google Colab.

## How to run
1. Download or clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Open `IMDB_Movie_Analysis.ipynb` in Jupyter Notebook, VS Code or Google Colab.
4. Run all cells from top to bottom. The notebook downloads `IMDB-Movie-Data.csv` automatically if the file is not already in the working directory. Internet access is required for the first download.

## Dataset
The notebook retrieves `IMDB-Movie-Data.csv` from a publicly hosted CSV at runtime. The dataset is not bundled with this repository.

EdiGlobe: *Machine Learning — Minor Project*, IMDb Analysis. The original assignment references an existing IMDb Analysis repository and asks learners to add further analyses.
